# Data acquisition
Source: https://turbulence.idies.jhu.edu/
Dataset: isotropic1024coarse. Velocity, unit spatial and temporal strides, filter width 1. One-based inclusive x/y/z ranges: R1 1–16, R2 129–144, R3 257–272, R4 513–528. T1–T5 correspond to simulation times 0, 0.002, 0.004, 0.006, 0.008. Grid spacing 2π/1024. Use authorized access and keep tokens in environment variables. Matched FD8/FD2 central subset removes four grid points from each face.
Canonical file: Project3_JHTDB_R1_R4_T1_T5.csv; reported SHA-256 5fe722114f486c9582c93017b66d0e57523806514845491976e5555a324e105e; 81,920 rows. Exclude incomplete 81,860-row upload. Raw data not distributed here. Check redistribution terms before release.
